# Security Policy

## Scope

This repository is primarily profile documentation and public automation. Security reports should focus on exposed credentials, unsafe workflow permissions, malicious dependencies, or compromised external references.

## Reporting

Please do not publish sensitive credentials or exploit details in a public issue. Contact the repository owner privately through the contact information on the GitHub profile.

## Safe handling

- Never commit API keys, tokens, passwords, or private data.
- Use GitHub Actions secrets for credentials required by automation.
- Prefer read-only permissions for workflows.
- Remove compromised credentials immediately and rotate them at the provider.
