# Contribution Strategy

The repository is designed to make meaningful engineering work visible without manufacturing activity.

## What is useful

- Improving reliability of profile automation
- Adding validation and tests
- Improving documentation
- Fixing broken links or rendering
- Updating project metadata when the underlying project changes
- Tightening workflow permissions

## What is not useful

Avoid empty commits, whitespace-only changes, repeated badge edits, or artificial history manipulation. Contributions should leave the repository better than they found it.

## GitHub contribution visibility

Commits on the repository default branch can appear on the author's contribution graph when GitHub's contribution criteria are satisfied. The repository therefore favors real changes on `main` rather than activity created solely for the graph.
