# Quality Gates

A profile change is considered ready when it passes these gates:

1. **Syntax** — Markdown and structured data are valid.
2. **Links** — internal paths and important external URLs are syntactically valid.
3. **Claims** — project and skill descriptions are supported by actual work.
4. **Automation** — workflows use explicit permissions and fail loudly.
5. **Maintainability** — recurring data has a clear source of truth.
6. **Presentation** — the profile remains readable on desktop and mobile.

These gates are intentionally lightweight so the repository can evolve without turning a profile README into a heavyweight application.
